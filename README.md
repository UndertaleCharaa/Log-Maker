# 🚀 Log-Maker (Simple Activity Logger)

Bash 쉘 환경에서 가볍게 동작하는 개인 활동 기록 프로그램입니다. 
제 첫 오픈소스 프로젝트입니다!

## ✨ 주요 기능
- **다국어 지원**: 한국어(KR), 영어(EN) 버전을 모두 지원합니다.
- **플랫폼 최적화**: 일반 리눅스 터미널과 안드로이드 Termux 환경에 맞춘 버전을 제공합니다.
- **의존성 없음**: 외부 라이브러리 없이 Bash 기본 기능만 사용하여 매우 가볍습니다.

## 🛠 실행 방법
```bash
# 1. 파일 실행 권한 부여 (예: 한국어 버전)
chmod +x log-kr.sh or chmod +x log-en.sh

# 2. 프로그램 실행
./log-kr.sh or ./log-en.sh
